# AI-Driven-Algorithmic-Trading
Set up an AI-powered trading environment, integrate live Kite APIs, build trading dashboards, create and optimize strategies with AI, backtest ideas, analyze options chains with live Greeks, and develop real-time scanners and alerts.

## About

This repository demonstrates how AI-assisted development can be used to build an algorithmic trading dashboard.To demonstrate how to build and extend an AI-powered algorithmic trading dashboard using Python, React, FastAPI, and Kite Connect.

The application was created using a combination of:

- AI-generated code (Codex/LLM prompts)
- Kite Connect Sandbox reference implementation
- Python (FastAPI)
- React + Vite

## Attribution

This project builds upon the Zerodha Kite Connect Sandbox/UAT environment.

Some components—particularly the authentication flow, Kite Connect integration, and initial dashboard scaffolding—were adapted from existing reference scripts and AI-assisted prompts rather than being written entirely from scratch.

My primary contributions include:

- Integrating and configuring the project
- Understanding and extending the existing codebase
- Building additional dashboard features
- Developing trading strategies
- Implementing screeners and backtesting modules
- Creating options analytics and visualization tools
- Improving the overall user interface and workflow


Tasks done:

Set up a complete AI-powered development environment using Codex, Python, and Node.js

Create and configure a Kite Developer account to access market data and trading APIs

Build trading dashboard by creating a login interface and integrating market data through Kite APIs

Use AI to build, combine, and optimize rule-based trading strategies using technical indicators and natural language prompts

Validate and refine trading strategies by running backtests, analyzing performance metrics, and iterating with your AI powered dashboard

Build an interactive options chain with live Greeks and real-time options market visualization

Use dashboard to analyze options data and build scanners for Open Interest(OI) walls, and implied volatility

Build options strategies using the dashboard and create alerts for timely adjustments
