# AI-Driven-Algorithmic-Trading
Set up an AI-powered trading environment, integrate live Kite APIs, build trading dashboards, create and optimize strategies with AI, backtest ideas, analyze options chains with live Greeks, and develop real-time scanners and alerts.

## About

This repository demonstrates how AI-assisted development can be used to build an algorithmic trading dashboard.To demonstrate how to build and extend an AI-powered algorithmic trading dashboard using Python, React, FastAPI, and Kite Connect.

The application was created using a combination of:

- AI-generated code (Codex/LLM prompts)
- Kite Connect Sandbox reference implementation
- Python (FastAPI)
- React + Vite

## Attribution

This project builds upon the Zerodha Kite Connect Sandbox/UAT environment.

Some components—particularly the authentication flow, Kite Connect integration, and initial dashboard scaffolding—were adapted from existing reference scripts and AI-assisted prompts rather than being written entirely from scratch.
